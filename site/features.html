Pipeline Builder

Declarative node sequencing with explicit inputs and outputs keeps dependencies visible and enforces deterministic runs.

  • Context-aware execution with `OrionContext`.
  • Autosave outputs that match catalog datasets.
  • In-memory data sharing between nodes.

Pipeline Builder

Sequenciamento declarativo de nodes com entradas e saídas explícitas mantém as dependências visíveis e garante execuções determinísticas.

  • Execução sensível ao contexto com `OrionContext`.
  • Autosave de outputs que correspondem ao catálogo.
  • Compartilhamento de dados em memória entre nodes.

Clean layer orchestration

Code stays testable and portable thanks to the separation between `core/`, `application/`, and `infrastructure/` modules.

  • `core/` — domain entities, interfaces, use cases.
  • `application/` — orchestrators, builders, CLI surface.
  • `infrastructure/` — connectors, context, persistence.

Orquestração em camadas limpas
