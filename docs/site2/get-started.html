Launch checklist

Checklist de lançamento

Lista de lanzamiento

1

Clone & set up environment

Navigate to the project directory and (optionally) activate an isolated virtual environment.

Clone e configure o ambiente

Navegue até o diretório do projeto e (opcionalmente) ative um ambiente virtual isolado.

Clona y configura el entorno

Ve al directorio del proyecto y (opcional) activa un entorno virtual aislado.

cd /Users/joseamaro/Documents/Estudos/orion_framework
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
2

Install Orion in editable mode

This exposes the orion CLI and ensures local changes are instantly reflected.

Instale o Orion em modo editável

Isso expõe o CLI orion e garante que alterações locais apareçam imediatamente.

Instala Orion en modo editable

Esto expone la CLI orion y asegura que los cambios locales se reflejen al instante.

pip install -e .
orion --help
3

Run the sample pipeline

Confirm that catalog loading, node execution, and autosave behaviors are functioning.

Execute a pipeline de exemplo

Confirme se o carregamento do catálogo, a execução dos nodes e o autosave estão funcionando.

Ejecuta la pipeline de ejemplo

Confirma que la carga del catálogo, la ejecución de los nodes y el autosave funcionan correctamente.

orion run \
  --module exemplo_get_started.pipeline \
  --catalog exemplo_get_started/catalog.yml

cat exemplo_get_started/data/processed/clientes_processados.csv
