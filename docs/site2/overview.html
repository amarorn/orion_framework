Visão Geral

O Oríon é um framework de engenharia de dados baseado em Clean Architecture e princípios SOLID. Ele foi projetado para criar pipelines de dados legíveis, idempotentes e observáveis.

Características Principais

  • Clean Architecture com separação clara de camadas
  • Type Safety com uso extensivo de type hints
  • Observabilidade com logging estruturado
  • Extensibilidade por meio de conectores plugáveis
  • Idempotência garantindo execuções determinísticas
  • Pipelines declarativas e legíveis

Arquitetura

O framework organiza o código em três camadas principais (Application, Core e Infrastructure), seguindo a regra de dependência onde camadas externas dependem somente de interfaces das camadas internas.

Fluxo de Dados

O pipeline do Oríon começa na CLI, carrega configurações, inicializa o OrionContext, e executa nodes que podem carregar dados via conectores como LocalCSV ou Databricks. 

CLI → Catalog → Context → Pipeline → Nodes → Connectors → Storage
