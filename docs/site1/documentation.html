🧭 Oríon Framework · Documentação Completa

O Oríon Framework é uma plataforma de engenharia de dados baseada em Clean Architecture e SOLID, projetada para pipelines declarativas, idempotentes e observáveis.

Visão Geral

Com o Oríon você constrói pipelines compostas por nodes (funções Python) que recebem um OrionContext com dependências resolvidas (catalog, logger e configurações). A execução sequencial garante previsibilidade e facilita o debugging.

  • Clean Architecture: separação clara de responsabilidades.
  • Type Safety: uso extensivo de type hints.
  • Observabilidade: logging contextual integrado.
  • Extensibilidade: conectores plugáveis.
  • Idempotência: execução determinística.

Guia rápido

Para iniciar um projeto, siga os passos do Guia de Início Rápido:

  1. Configure diretórios e catalog.yml.
  2. Implemente funções extract, transform e load.
  3. Monte a pipeline com PipelineBuilder.
  4. Execute com orion run.

Conceitos fundamentais

  • Node: função que recebe context e inputs e devolve outputs.
  • Pipeline: sequência ordenada de nodes.
  • Data Catalog: mapeia nomes lógicos para conectores físicos.
  • OrionContext: injeta dependências durante a execução.

Guia de uso

Definição de pipeline

from orion_framework.application.pipeline.builder import PipelineBuilder
from .nodes import extract, transform, load

def create_pipeline():
    builder = PipelineBuilder("pipeline_clientes")
    builder.add_node(extract, inputs=[], outputs=["clientes_raw"])
    builder.add_node(transform, inputs=["clientes_raw"], outputs=["clientes_processados"])
    builder.add_node(load, inputs=["clientes_processados"], outputs=[])
    return builder.build()

Execução

orion run \
  --module examples.pipeline_clientes.pipeline \
  --catalog examples/catalog.yml

Catalog

clientes_raw:
  type: local_csv
  path: data/raw/clientes.csv

clientes_processados:
  type: databricks
  table: analytics.clientes_processed
  mode: overwrite

API Reference

  • PipelineBuilder.add_node(func, inputs, outputs): adiciona etapas.
  • OrionContext.catalog: acesso a load e save.
  • PipelineRunner.run(pipeline, context): executa pipelines.
