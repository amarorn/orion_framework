Localization strategy

Keep English and Portuguese guides synchronized to ensure cross-team alignment.

Estratégia de localização

Mantenha os guias em inglês e português sincronizados para garantir alinhamento entre equipes.

Estrategia de localización

Mantén sincronizadas las guías en inglés y portugués para asegurar el alineamiento entre equipos.

  • Mirrored pages: When updating QUICKSTART.md, replicate content in both languages. Páginas espelhadas: Ao atualizar o QUICKSTART.md, replique o conteúdo em ambos os idiomas. Páginas espejo: Al actualizar QUICKSTART.md, replica el contenido en ambos idiomas.
  • Glossary: Maintain consistent terminology (e.g., “Pipeline”, “Data Catalog”). Glossário: Mantenha a terminologia consistente (ex.: “Pipeline”, “Catálogo de Dados”). Glosario: Mantén la terminología consistente (p. ej., “Pipeline”, “Catálogo de Datos”).
  • Navigation: The doc portal (`docs/index.md`) offers bilingual entry points—update it whenever new guides land. Navegação: O portal de docs (`docs/index.md`) oferece entradas bilíngues — atualize-o sempre que surgirem novos guias. Navegación: El portal de docs (`docs/index.md`) ofrece accesos bilingües — actualízalo cada vez que lleguen nuevas guías.
  • Automation: Configure bots to flag sections that drift across translations. Automação: Configure bots para sinalizar seções que divergirem entre traduções. Automatización: Configura bots para señalar secciones que difieran entre traducciones.
