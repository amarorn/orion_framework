Governança de Dados com Oríon

Estabeleça confiança e rastreabilidade nas suas pipelines utilizando catálogos versionados, validações de esquema e políticas de acesso centralizadas.

🗂️ Catálogo como Fonte de Verdade

Todos os datasets do Oríon são declarados em arquivos catalog.yml, que descrevem localização, formato, credenciais e políticas de versionamento.

  • Versionamento: utilize campos version para congelar insumos críticos.
  • Metadados: tags opcionais ajudam a classificar sensibilidade e domínio de negócio.
  • Auditoria: combine com conectores que registram lineage (ex.: Databricks Unity Catalog).

🔐 Controles de Acesso

O framework isola credenciais através do OrionContext, evitando que dados sensíveis sejam expostos diretamente nas funções de node.

Scopes mínimos

Crie usuários de serviço com permissões apenas de leitura/escrita necessárias.

Segredos externos

Integre com Azure KeyVault, AWS Secrets Manager ou Databricks Secrets.

Masking dinâmico

Implemente hooks nos conectores para anonimizar dados antes de persistir.

🧭 Trilha de Auditoria

Cada execução do PipelineRunner pode emitir eventos estruturados via logger padrão. Configure destinos adicionais para compor um trilho completo de auditoria:

  • Envie logs para o Data Catalog corporativo ou sistemas SIEM.
  • Inclua identificadores de lote, usuário executor e hash do pipeline.
  • Acompanhe alterações de schema comparando snapshots gerados automaticamente.

✅ Checklist de Governança

Documentação

Defina responsáveis

Mapeie donos técnicos e de negócio para cada dataset crítico.

Qualidade

Monitore contratos

Valide schema e regras de qualidade a cada execução do pipeline.

Conformidade

Automatize revisões

Gere relatórios periódicos com status de controles e exceções.
